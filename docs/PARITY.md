# 与桌面版 ZCode 的能力对照

目标不是把桌面 UI 塞进手机，而是让**同一套工作方式**在手机上成立：登录同一账号、用同一份额度、在同一个工作区里读文件、跑命令、改代码、验证结果。

图例：✅ 已实现 · 🟡 手机上的替代做法 · ⏳ 尚未实现

## 账号与会话

| 能力 | 手机版 | 说明 |
|---|---|---|

| 令牌自动续期 | ✅ | 到期前 2 分钟换新，长会话不断 |
| 多会话 / 置顶 / 归档 / 搜索 | ✅ | 抽屉分组：置顶 / 今天 / 昨天 / 7 天 / 更早 |
| 会话复制（fork） | ✅ | 复制完整记录，便于从同一上下文试两种方案 |
| 会话导出 | ✅ | 导出 Markdown 到剪贴板 |
| 跨设备同步 | ⏳ | 目前为本地存储；配置串可导出/导入 |

## 设计取舍

1. **不引入 WebView**：所有界面是原生 Flutter 组件，滚动、键盘、返回手势都按 Android 习惯走。
2. **工作区就是真目录，不用 SAF 的 document id**：拿到 All-files 权限后直接用 `java.io` / `dart:io`，路径对终端、对 Termux、对其他 App 完全一致。SAF 虽然免权限，但每条路径都要换 document id，`git` 和脚本会处处别扭。
3. **运行时交给 Termux，而不是打包进去**：Android 10+ 禁止从应用可写目录 exec，自带 node 也跑不动；Termux 是系统认可的正规 prefix，还能和 App 共用同一个文件夹。常用 shell 工具则做成可安装模块，技能、命令、子智能体、MCP 做成「下载即用」的插件，写进 `.zcode/` 即生效。
4. **权限是可以拒绝的**：拒绝之后 App 退回私有目录并明确提示，而不是白屏或假装能读。
5. **手机优先的密度**：工具卡、计划卡默认折叠/紧凑，重要信息（命令、退出码、token）一眼可见，细节点开再看。
