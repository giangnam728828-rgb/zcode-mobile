# 与桌面版 ZCode 的能力对照

目标不是把桌面 UI 塞进手机，而是让**同一套工作方式**在手机上成立：登录同一账号、用同一份额度、在同一个工作区里读文件、跑命令、改代码、验证结果。

图例：✅ 已实现 · 🟡 手机上的替代做法 · ⏳ 尚未实现

## 账号与会话

| 能力 | 手机版 | 说明 |
|---|---|---|
| 平台账号 OAuth 登录 | ✅ | 浏览器授权 + `127.0.0.1` 回跳，Keystore 存令牌 |
| 与桌面端共用套餐 | ✅ | 使用账号签发的 Project Token，不填 API Key |
| 令牌自动续期 | ✅ | 到期前 2 分钟换新，长会话不断 |
| 多会话 / 置顶 / 归档 / 搜索 | ✅ | 抽屉分组：置顶 / 今天 / 昨天 / 7 天 / 更早 |
| 会话复制（fork） | ✅ | 复制完整记录，便于从同一上下文试两种方案 |
| 会话导出 | ✅ | 导出 Markdown 到剪贴板 |
| 跨设备同步 | ⏳ | 目前为本地存储；配置串可导出/导入 |

## 设计取舍

1. **不引入 WebView**：所有界面是原生 Flutter 组件，滚动、键盘、返回手势都按 Android 习惯走。
2. **不申请存储权限**：工作区在应用私有目录，卸载即清理；代价是不能直接改手机其他目录。
3. **能力靠模块和插件扩展**：Android 不自带 node/python，与其塞一个 150MB 的运行时，不如把常用 shell 工具做成可安装模块；技能、命令、子智能体、MCP 则做成「下载即用」的插件，写进 `.zcode/` 就生效，不用重新打包 APK。
4. **手机优先的密度**：工具卡、计划卡默认折叠/紧凑，重要信息（命令、退出码、token）一眼可见，细节点开再看。
